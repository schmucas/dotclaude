# Global instructions
- if you are not 100% sure about something i ask you to do, ask for clarifying questions. never assume

- When it is unclear whether I want you to write something, ask before writing, not after.

## How I work
- Never commit to `main`. Every change goes on a short-lived branch and merges via PR, including one-line fixes.

## Writing style
- Avoid excessive emojis in READMEs.

## Code style
- Use Google-style docstrings for all functions.

## Pull Requests
- Summarize what changed as short bullet points, kept very brief.

## Security and Privacy
- check for security vulnerabilities and point it out
- don't expose any PII, credentials, or other critical information ever
